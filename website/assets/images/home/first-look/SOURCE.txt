Home page, "A first look": where these files come from.

Each file is the solution figure PINNStudio's own Solve script wrote (plot type set to the animation shown,
Line/Surface Animation or Parameter Convergence; Surface for the steady Kovasznay flow), from one run of the
built-in example with Settings: Tuned (the example's own settings where it has no Tuned entry), seed 2026, on an
RTX 4090, from commit b7f2108 (branch fix/v1.6.0-consistency). Workstation jobs zzzzzv4_gallery_anim6 and
zzzzzv3_gallery_kovasznay (tools: the job script gallery_anim.py; animation settings 30 time frames, 100 dpi, 60
parameter frames). The files were then scaled to 480 px wide (360 px for the tall Lorenz figure) and saved with a
smaller colour palette; nothing else was changed.

Each run's errors are in its log.txt in the job folders above; they are of the same size as the benchmark
records of the example (benchmarks/examples.md). The Lorenz run recovered C1 = 10.0034, C2 = 14.9996,
C3 = 2.66643 (true 10, 15, 8/3).
