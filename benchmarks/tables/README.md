# Benchmark records: per-seed values and the paper's tables

Generated by `tools/make_benchmarks_readme.py` from the same study records as Figure 4 (`figures/paper_figure.pdf`),
the benchmark pages and the Tuned presets (`pinnstudio/resources/tuned_settings.json`). Do not edit by hand.

| File | Contents |
|---|---|
| `forward_per_seed.csv` | Every forward run behind the pages: example, variant (configuration), seed, the main output's relative L₂ error at the last reference time, and every output's. `selected` marks the configuration reported as tuned, `starting` the starting configuration (DeepXDE's example settings, or the published method run in PINNStudio). |
| `inverse_per_seed.csv` | Every inverse run: example, variant, seed, each unknown's true and recovered value, its relative error, and the run's worst relative parameter error. `selected` marks the tuned configuration. |
| `table_s2.tex` | Supplementary Table S2 (LaTeX rows): the tuned configuration's relative L₂ error of each output at the last reference time, outputs in the example's own order. |

## Definitions

- **Seeds.** Every value in Figure 4 (forward tuned and starting values, inverse values) is the median over seeds 2026, 1 and 2 of the configuration shown. Outside Figure 4, some configurations were run with seed 2026 only; the CSV files list the seeds each value rests on.
- **Forward error.** Relative L₂ error ‖û − u_ref‖₂ / ‖u_ref‖₂ at the reference points of the last reference time, for the main output (for Cahn–Hilliard problems the selection also checks the chemical potential μ); per output in Table S2. The reported value is the median over the seeds.
- **Inverse error (scalar unknowns).** For each seed, the relative error 100 |θ̂ − θ*| / |θ*| of every unknown, and the largest of them (the seed's worst parameter error); the reported value is the median of these per-seed worst errors over the seeds. In Figure 4 each unknown's diamond is the median over the seeds of that unknown's error. Errors below 10⁻⁴ % are drawn at 10⁻⁴ %.
- **Inverse error (unknown function).** For Poisson 1D with an unknown forcing, the relative L₂ error (in %) of the recovered function.
- **Thresholds.** "Below 1 %" means a relative error below 10⁻² (forward) or a worst parameter error below 0.01 (as a fraction); "below 0.1 %": 10⁻³.
- **Selection (tuned configuration).** The candidate configurations of each example (its own settings, the tuning study's variants, and for the paper templates the published methods run in PINNStudio) are compared by their median error against the reference; among those within 25 % of the lowest, the fastest (median training time) is chosen; the example's own settings are kept if they are within 25 % of the lowest error and within 10 % of the fastest time. This selection is guided by the reference solutions; the seeds evaluate the selected configuration, they are not themselves tuned.
- **Reference data.** The reference solutions are in `reference_data/` (analytical solutions written at the evaluation points, or numerical reference solutions); the Poisson disk/sphere (exact), Poisson L-shape (refined finite differences) and Burgers 2D (Chebyshev spectral) references were regenerated and validated as described in `benchmarks/reference_regeneration/README.md`.
