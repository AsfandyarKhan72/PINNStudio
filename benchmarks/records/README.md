## What is in each folder

- `*.jsonl`: one line per training run, as written by `tools/tuning_study.py` (example, mode, variant, seed,
  network, training phases, points, run time, final loss, printed errors, inverse parameter estimates).
  The run's configuration is the template's configuration with the variant applied (`tools/tuning_study.py`,
  `pinnstudio/core/paper_settings.py`); the selected configurations are also saved as problem files in
  `benchmarks/tuning/`.
- `primary.json`: each run's main-output relative L2 error at the last reference time and every output's error,
  read from the run logs (`OUTS` in `tools/make_benchmarks_readme.py`).
- `spacetime*.json`: each run's error over all reference times.
- `results_args.txt`, `papers_arg.txt`, `spacetime_arg.txt`: which files the build reads, in order.
- corrected build only:
  - `reeval_all.json` and `reeval_bundles/`: the saved forward runs re-scored against the regenerated
    references (predictions and the re-computed errors).
  - `changes.md`: every value that changed from the original build and why (re-scored, or left out and trained
    again).
  - `a13_*`, `a14_*` and `new_primary.json`: the retrained inverse runs.
- `original_2026-10-30/primary_final.json`: the primary file the original build used, and the one the corrected
  build started from (`benchmarks/reference_regeneration/apply_reeval.py --primary`).
  `original_2026-10-30/primary.json` is an earlier version without the seed-1/seed-2 runs of the papers'
  methods; it is kept for the record but not used (with it, 16 rows of `forward_per_seed.csv` fall back to the
  worst printed error and differ from the committed file).

The run folders themselves (logs, models, figures) stay on the GPU machine; only these summaries are kept here.

## Rebuilding

From a checkout of the commit that produced the build (its `tools/` and `benchmarks/tuning/readme_results.json`):

```bash
B=benchmarks/records/corrected_2026-10-31; P=$B/primary.json        # corrected build, on this branch
# B=benchmarks/records/original_2026-10-30; P=$B/primary_final.json  # original build, at commit af321c1
python tools/build_benchmark_records.py $(sed "s#^#$B/#" $B/results_args.txt) \
    --primary $P \
    --papers "$(sed "s#^#$B/#" $B/papers_arg.txt | paste -sd,)" \
    --spacetime "$(sed "s#^#$B/#" $B/spacetime_arg.txt | paste -sd,)" \
    --out /tmp/records_check
diff /tmp/records_check/table_s2.tex benchmarks/tables/table_s2.tex
```

`tools/build_benchmark_records.py` writes `table_s2.tex`, `forward_per_seed.csv`, `inverse_per_seed.csv`
and the Figure 4 rows with the same functions as `tools/make_benchmarks_readme.py`.

The last independent rebuild of both builds and the differences between them are in [`VERIFICATION.md`](VERIFICATION.md).

## Regenerating the pages

The pages are written from the same files (corrected build, from a checkout of this branch):

```bash
B=benchmarks/records/corrected_2026-10-31
# benchmarks/tuning_study.md, figures/tuning_summary.png and the tuned problem files in benchmarks/tuning/
python tools/make_tuning_page.py $(sed "s#^#$B/#" $B/results_args.txt) --primary $B/primary.json
# benchmarks/README.md, benchmarks/examples.md, benchmarks/paper.md, figures/benchmarks_summary.* and paper_figure.*
python tools/make_benchmarks_readme.py $(sed "s#^#$B/#" $B/results_args.txt) --primary $B/primary.json \
    --papers "$(sed "s#^#$B/#" $B/papers_arg.txt | paste -sd,)" \
    --spacetime "$(sed "s#^#$B/#" $B/spacetime_arg.txt | paste -sd,)"
```

Both read `benchmarks/tuning/readme_results.json` and `pinnstudio/resources/tuned_settings.json` as well; run them
with `QT_QPA_PLATFORM=offscreen` and `MPLBACKEND=Agg` on a machine without a display. Memory: `make_tuning_page.py`
peaks at about 2 GB; `make_benchmarks_readme.py` at about 6.7 GB (it loads every example's reference data and draws
the figures), so it needs a machine with at least 8 GB free; on 8 GB in all it is killed. The figures use the Inter
typeface: without it installed, matplotlib falls back to another font, so the figures differ in their lettering
(not their values) from the committed ones.

Checked on 2026-11-02 at commit `5c32644`: `make_tuning_page.py` (Python 3.13, CPU) reproduces
`benchmarks/tuning_study.md` byte for byte; the tuned problem files differ only by the field `ta_backward_seed: -1`
(added to the configuration later; -1 is also its default when a file does not have it, and no tuned file uses
backward compatibility). `make_benchmarks_readme.py` (GPU workstation, Python 3.11, CPU only) rebuilds Table S2 and
both per-seed tables identically. Its pages match the committed ones except the Settings toggles of five DeepXDE
inverse examples (Brinkman-Forchheimer, Diffusion 1D – unknown coefficient, Diffusion-reaction 1D – unknown rate
field, Poisson 1D – unknown forcing field and its batches version): the committed `benchmarks/README.md` was written
before their Tuned settings were offered, and listed their Default settings as PINNStudio's best. Those five toggles
were then taken from the workstation's output (commit after 351c21f) and checked against the settings PINNStudio
loads as *Tuned* for each (network, points, training phases: identical); the regenerated figures were not taken
(same values, other typeface).

The workstation run: `.gpu_runner/done/q1_regen_pages/` (clone of `integration/v1.6.0-final` at 5c32644,
`python tools/make_benchmarks_readme.py` with the arguments above, CPU only, Python 3.11.5, PySide6 6.11.3; exit 0,
peak memory 6,734,100 kB; `tools/build_benchmark_records.py` with the same arguments: `table_s2.tex`,
`forward_per_seed.csv` and `inverse_per_seed.csv` identical to the committed files).

Note on the two pages' selection rules for these five examples (DeepXDE's own inverse examples, which the tuning
study ran in their forward setting): `tuning_study.md` picks the change with the lowest final training loss
(*Chosen: all* for Brinkman-Forchheimer, Diffusion 1D and Diffusion-reaction 1D), while `benchmarks/README.md` and
`pinnstudio/resources/tuned_settings.json` use the inverse-problem rule of that page (the error of the learned
parameters or field, and the fastest within 25%: *iters*, *iters*, *net*). Both follow from the same records; what
PINNStudio loads as *Tuned* is the latter.
